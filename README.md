# TPO-LAB-2 (Kotlin)

Приложение вычисляет систему функций:

- при x <= 0:
  ((((cos(x) * sec(x)) * sin(x)) * sec(x)) * cos(x))^2
- при x > 0:
  (((log_2(x) + log_5(x) + log_2(x))^3)^2) / log_5(x)

## Что реализовано

- Базовые функции через ряды:
  - sin(x): ряд Тейлора
  - ln(x): степенной ряд через преобразование и нормализацию аргумента
- Остальные функции выражены через базовые:
  - cos(x) через sin(pi/2 - x)
  - sec(x) через 1/cos(x)
  - log_b(x) через ln(x)/ln(b)
- Система функций с ветвлением по x
- Экспорт результатов любого модуля в CSV формата x;result с настраиваемым шагом
- Интеграционные тесты для модулей и системы
- Табличные заглушки для каждого модуля: SinStub, CosStub, SecStub, LnStub, Log2Stub, Log5Stub, SystemStub

## Структура модулей

- System
  - Trig group
    - Cos (через Sin)
    - Sec (через Cos)
    - Sin (базовая)
  - Log group
    - Log2 (через Ln)
    - Log5 (через Ln)
    - Ln (базовая)

## ОДЗ и взаимозависимые точки

- sin(x): x в R
- cos(x): x в R
- sec(x): x != pi/2 + pi*k, k в Z
- ln(x): x > 0
- log_2(x), log_5(x): x > 0
- Система:
  - x <= 0: дополнительно sec(x) определена, т.е. x != pi/2 + pi*k
  - x > 0: дополнительно log_5(x) != 0, т.е. x != 1

Критичные взаимозависимости:

- cos(x) зависит от sin(pi/2 - x)
- sec(x) зависит от cos(x) и теряет определенность в нулях cos(x)
- log_2(x), log_5(x) зависят от ln(x)
- Для системы важны точки разрыва ветвей и знаменателей: x = pi/2 + pi*k (левая ветвь), x = 1 (правая ветвь)

## Запуск тестов

Требуется Gradle (проверено на Gradle 9.4.1):

gradle test

## Запуск экспорта CSV

Пример для системы:

gradle run --args="--module system --from -2 --to 2 --step 0.5 --eps 1e-6 --out out/system.csv --delimiter ;"

Доступные модули:

sin, cos, sec, ln, log2, log5, system
